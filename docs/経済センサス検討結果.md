# 経済センサスデータの検討結果

## 概要

経済センサスの「産業(小分類)別民営事業所数(雇用者のいない個人経営の事業所を除く)」データ（`c1_004_1a.xlsx`）を分析し、OpenStreetMapのPOIデータの代替可能性を検討しました。

## データ構造

### エクセルファイルの構造

- **総行数**: 1,973行
- **総列数**: 767列
- **ヘッダー**: 行7に産業分類名、行10以降がデータ
- **地域区分**: 全国、都道府県、市区町村（1,961市区町村）

### 産業分類

- **産業分類数**: 765種類
- **主要分類**:
  - AR*全産業（S*公務を除く）
  - AB\_農林漁業
  - A\_農業、林業
  - 01\_農業
  - 010*管理、補助的経済活動を行う事業所（01*農業）
  - 011\_耕種農業
  - 012\_畜産農業
  - その他多数

## 結論: OpenStreetMapとの代替可能性

### ✅ 経済センサスデータは都会度算出に活用可能

### メリット

1. **公的統計で信頼性が高い**
   - 総務省統計局による公式データ
   - 全数調査で網羅性が高い
   - データの正確性が保証されている

2. **全国一律の基準で集計されている**
   - 産業分類が統一されている
   - 地域間の比較が容易
   - バイアスが少ない

3. **市区町村単位で正確な事業所数が得られる**
   - 1,961市区町村をカバー
   - 産業分類別の詳細データ
   - 総事業所数が明確

### デメリット

1. **5年ごとの更新でデータが古い可能性**
   - 令和6年（2024年）のデータ
   - 次回更新は2029年
   - リアルタイム性に欠ける

2. **産業分類とPOIカテゴリの対応付けが必要**
   - 産業分類（765種類）とOSMのPOIタグの対応が複雑
   - マッピングルールの作成が必要
   - 完全な対応は困難

3. **地理座標情報がない（市区町村単位のみ）**
   - 施設の正確な位置情報なし
   - 市区町村内の分布が不明
   - 空間的な分析に制限

## 推奨される活用方法

### 1. OSMデータの「補完」として使用

- OSMデータが不足している地域の補正
- POI数が極端に少ない市区町村のデータ補完
- 信頼性の向上

### 2. 「非農林漁業」事業所数を新たな都会度指標として使用

- **「全産業」ではなく「非農林漁業（公務を除く）」を使用**
- 農林漁業を除外することで、純粋な都市的経済活動を測定
- 公務を除外することで、行政機能の影響を排除
- 現在の4層（夜間光・人口・POI・地価）に加えて、第5の指標として活用

### 3. 既存のPOIスコアとの相関を分析

- POIスコアと事業所数の相関係数を算出
- 乖離が大きい地域を特定
- スコアの妥当性を検証

### 4. ハイブリッドスコアの算出

```
ハイブリッドPOIスコア = α × OSM_POIスコア + β × 経済センサススコア
```

- OSMデータが充実している地域: α=0.8, β=0.2
- OSMデータが不足している地域: α=0.3, β=0.7

## まとめ

経済センサスデータは、OpenStreetMapのPOIデータを**完全に代替することはできない**が、**補完データとして非常に有用**です。

特に以下の用途で活用できます：

1. **OSMデータの検証**: POIスコアの妥当性チェック
2. **データ補完**: OSMデータが不足している地域の補正
3. **新指標の追加**: 総事業所数を第5の都会度指標として活用
4. **精度向上**: ハイブリッドスコアによる都会度算出の精度向上

今後は、経済センサスデータをスコア化し、既存のPOIスコアと組み合わせることで、より信頼性の高い都会度スコアを算出することを推奨します。
